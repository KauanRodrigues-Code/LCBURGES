🍔 LC BURGERS - Cardápio Digital
Cardápio interativo para hamburguerias com sistema de carrinho e envio de pedidos via WhatsApp.

✨ Funcionalidades
Categorias: Tradicionais, Gourmets e Bebidas.

Carrinho: Adição/remoção de itens com atualização de preço em tempo real.

Entrega/Retirada: Opção de informar endereço ou retirar no local.

Pagamento: Suporte para Pix, Cartão e Dinheiro (com troco).

WhatsApp: Envio automático do resumo do pedido formatado.

🛠️ Tecnologias
HTML5, CSS3 e JavaScript.
